# SmartSTB Clone for Samsung Tizen TV

A lightweight, custom Tizen TV web application built to interface with Stalker portals using native JavaScript and the Samsung `avplay` video player API.

## Features
* **Live TV, VOD (Movies), and Series Support:** Clean 3-column UI layout optimized for TV remote navigation.
* **Smart VOD Seeking:** Accelerated multi-step seeking (30s to 10m) and percentage jumps (`0`–`9` keys).
* **Live EPG:** Built-in Now/Next program guide preview.
* **Customization:** Multiple theme accents (Blue, Green, Red, Amber) and portal settings modal.

## Disclaimer
This project is an independent media client. It does not provide, bundle, or distribute any media streams, content, or portal subscriptions. Users must supply their own backend proxy and portal credentials.
